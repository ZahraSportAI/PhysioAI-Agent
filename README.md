# 🧠 PhysioAI-Agent
### اولین دستیار هوشمند عامل‌محور (Agentic Workflow) در حوزه فیزیولوژی ورزشی ایران

**توسعه‌دهنده:** زهرا احمدی 

زمینه تخصصی: فیزیولوژی ورزش (کارشناس ارشد) + توسعه کاربردهای هوش مصنوعی

هدف شغلی: AI Application Developer | Focused on Health & Sports Tech
---

## 🎯 چشم‌انداز پروژه
سیستمی که با دریافت داده‌های فیزیولوژیک (ضربان قلب، لاکتات، VO2max، و ...) بتواند **برنامه‌های تمرینی و توانبخشی شخصی‌سازی‌شده** ارائه دهد.

---

## 🧰 ابزارها و تکنولوژی‌ها
| دسته‌بندی | ابزارها |
|-----------|---------|
| **مدل‌سازی و Agent** | LangChain, ReAct Agent |
| **ذخیره و بازیابی** | RAG, ChromaDB |
| **سرویس و API** | FastAPI, Docker |
| **زبان برنامه‌نویسی** | Python 3.10+ |
| **ابزارهای جانبی** | Git, GitHub, Streamlit |
